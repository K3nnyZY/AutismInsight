# Documentos

Coloca aquí PDF con texto, TXT o Markdown UTF-8 que quieras indexar. La ingesta es
una operación del administrador y puede enviar el contenido del documento a OpenAI.
No incluyas expedientes, datos de menores ni contenido identificable de pacientes.

El PDF original se conserva en `Server/app/Asperger.pdf` y se indexa como `demo`.
`reviewed` es una clasificación que debe asignar una persona después de revisar
la fuente, su actualidad y los permisos de uso; el software no certifica su calidad.
